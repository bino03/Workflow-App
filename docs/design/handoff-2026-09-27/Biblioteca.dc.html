Quando usar

SPAs internas com muitos formulários e tabelas, onde a consistência do Ant Design poupa tempo e o Tailwind cobre o estilo próprio. Não usar para sites de conteúdo.

Estrutura
src/ app/ # rotas e layout features/ # um diretório por domínio theme/ # tokens --wfa-* → ConfigProvider vite.config.ts
Decisões
—Tema do Ant Design gerado a partir das CSS custom properties.
—Tailwind 4 só para layout e espaçamento; nada de cores soltas.
—Estado de servidor com @tanstack/react-query.
